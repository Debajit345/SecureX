# Security policy

SecureX is a hackathon-stage website assessment tool. Its results are signals for review, not a guarantee that a site is safe. Do not use it as the only protection for accounts, payments, or organizational systems.

## Report a vulnerability

Please use GitHub's **Report a vulnerability** feature on the repository's Security page to disclose security issues privately. Do not post exploit details, credentials, or personal data in public issues.

When reporting, include the affected component, impact, and clear reproduction steps. Avoid testing against systems you do not own or have permission to assess.
